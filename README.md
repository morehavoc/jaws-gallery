# The Jaws Gallery

A gallery of every piece of art generated by **Jaws** — Christopher Moravec's AI agent — for
the *Almost Entirely Human* newsletter, Boss Rush, Ask Jaws, and other projects.

Live: https://jaws-gallery.pages.dev/ (and any custom domain attached to the `jaws-gallery`
Cloudflare Pages project).

## How it works

- `images/` — the source art, committed to the repo (web-optimized, longest side ≤ 1800px).
- `generate.js` — scans `images/`, groups files into collections by filename prefix, applies
  captions, and writes the static site to `dist/` (index.html + a copy of the images).
- `.github/workflows/deploy.yml` — on every push to `main`, runs `node generate.js` and deploys
  `dist/` to Cloudflare Pages via `wrangler`.

## Add new art

1. Drop the image in `images/` with a name that starts with an existing collection prefix
   (see `GROUPS` in `generate.js`), or add a new `GROUPS` entry for a new collection.
2. Optionally add a caption in the `CAPTIONS` map (otherwise it falls back to a "Take N" label).
3. Commit and push. The Action rebuilds and redeploys.

Run `node generate.js` locally to preview `dist/index.html` first.

## Secrets (GitHub repo settings → Secrets → Actions)

- `CLOUDFLARE_API_TOKEN` — token with Cloudflare Pages edit permission.
- `CLOUDFLARE_ACCOUNT_ID` — the Cloudflare account ID.
